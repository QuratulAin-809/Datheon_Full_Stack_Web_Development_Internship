# Developer Portfolio

A responsive, modern personal portfolio website built with plain HTML5, CSS3 and JavaScript (ES6+).

**Live demo:** https://github.com/QuratulAin-809/

## Features

- Semantic HTML5 structure: Header, Hero, About, Skills, Projects, Contact
- Mobile-first responsive layout using Flexbox and CSS Grid
- Dark / light theme toggle (remembers your choice and respects system preference)
- Mobile hamburger menu
- Project detail modals (keyboard accessible, closes with Esc)
- Smooth scrolling navigation
- No frameworks or build step needed

## Tech Stack

HTML5, CSS3, JavaScript (ES6+), deployed on GitHub Pages
